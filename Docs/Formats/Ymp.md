# YMP 패턴·노트

코드: `Parsing/Submodules/PatternParser.cpp`, `Model/Submodules/PatternDocument.h`.
노트 ID·표시 계약: `YOUMU.Modes/Taiko/Submodules/TaikoNoteDefinition.h`.
위치/BPM 변경일 때만 [Timing](Timing.md), 사운드 변경일 때만 [YME](Yme.md)를 읽습니다.

UTF-8 텍스트이며 빈 줄과 `//`로 시작하는 줄을 무시합니다. 경로에는 `\\`와 `/`를 사용할 수 있습니다.

### Metadata와 Difficulty

```text
[Metadata]
Music metadata: Music/Angeldream/angel dream hand shaking.ymm
Effect file: angeldream [long notes test].yme
BG: abcd/bg1.png
offset: 0, 0
Pattern Maker Count: 1
Pattern Maker 1: Maker Name
Pattern Name: Long Notes Test
Tags: test,long-note

Pattern Offset: 104
Base BPM: 180

[Difficulty]
Mode: Taiko
JudgeLevel: 50.00
```

| 필드 | 의미 |
| --- | --- |
| `Version` | 정수 형식 버전입니다. 생략하면 1입니다. |
| `Music metadata` | Songs 루트를 기준으로 한 YMM 상대 경로입니다. catalog가 YMM과 YMP를 연결할 때 사용합니다. |
| `Effect file` | YMP 폴더 기준 YME 경로입니다. 효과가 없으면 생략할 수 있습니다. 같은 이름 YME를 자동 검색하지 않습니다. |
| `BG` | 선택한 Songs 폴더의 `BG` 하위 기준 이미지 경로입니다. `abcd/bg1.png`는 `Songs/BG/abcd/bg1.png`입니다. 생략/빈 값은 기존 배경을 사용합니다. |
| `offset` | 배경 중심의 `x, y` 오프셋입니다. 기본 `0, 0`. 엔진 2D 논리 좌표(기준 높이 720), +X 오른쪽/+Y 위쪽입니다. `Pattern Offset` 시간 보정과 별개입니다. |
| `Pattern Maker ...` | 제작자 문자열입니다. `Pattern Maker Count`는 현재 개수 검증에 사용하지 않습니다. |
| `Pattern Name` | 곡 선택 화면에 표시할 패턴 이름입니다. |
| `Tags` | 쉼표로 구분한 패턴 태그입니다. |
| `Pattern Offset` | 밀리초 단위 패턴 오프셋입니다. 양수이면 모든 노트가 늦어집니다. |
| `Base BPM` | 최초 BPM입니다. 0보다 커야 하며, 생략하면 120입니다. |
| `Mode` | 플레이/에디터 진입에 필요한 명시적 모드입니다. 현재 지원 값은 `Taiko`입니다. 빈 값을 Taiko로 대체하지 않습니다. |
| `JudgeLevel` | 판정 창 크기를 정하는 1.00~100.00 고정소수점 값(0.01 단위)입니다. 생략하면 50.00입니다. 값이 커질수록 판정 창이 좁아집니다. |

`JudgeLevel`은 정수 표기(예: 50)도 읽으며 저장할 때 50.00처럼 두 자리를 고정합니다.
범위 밖 값·유효한 소수 셋째 자리·NaN/무한대는 오류입니다. 내부 값은 JudgeLevel의
100분의 1 단위 정수이며 판정 프로필·HUD·결과 snapshot까지 같은 값을 전달합니다.

### HP 게이지 설계 (미구현)

아래는 합의된 기본 게이지 동작을 정리한 설계이며, 현재 YMP 파서나 게임에
구현된 기능이 아닙니다. HP 관련 YMP 필드명, 문법, 저장 위치와 기본값 적용 방식은
아직 정해지지 않았습니다. `JudgeLevel`은 판정 범위 설정으로, 체력 레벨과 별개입니다.

- 기본 게이지는 HP 0%에서 시작하며 0~100% 범위로 제한합니다. HP가 0%에 도달해도
  곡을 중단하거나 합격 자격을 잃지 않고 이후 판정으로 회복할 수 있습니다.
- 곡 종료 시 HP 60% 이상이면 기본 게이지 합격입니다. 여러 종류의 게이지를 동시에
  계산해 달성한 가장 높은 등급으로 판정하는 플로팅 게이지를 계획합니다. 다른
  게이지의 규칙과 등급 순서는 아직 정해지지 않았습니다.
- TOTAL은 120%p이며 기본 체력 레벨 후보는 9입니다. 게이지에 반영되는 판정 단위
  수를 `N`이라고 할 때 기본 증가량은 `120%p / N`, 나쁜 판정의 감소량은 기본
  증가량의 9배입니다. TOTAL은 HP 상한을 무시하고 각 노트의 전체 가중치에 최대
  회복률을 적용했을 때의 이론적 회복 합계이지 HP 상한이 아닙니다.
- MAX와 PERFECT는 기본 증가량에 해당 입력의 가중치를 곱한 값의 100%, GOOD은 변화
  없음, MISS/BAD는 해당 가중치의 기본 감소량을 적용합니다. GREAT는 타격 오차의 크기를 PERFECT와 GREAT 판정 구간의
  경계 사이에서 선형 보간해 PERFECT 쪽에서 100%, GOOD 쪽에서 0%를 적용합니다.
  빠른 타격과 늦은 타격에 같은 규칙을 적용합니다.
- 나쁜 판정 5%는 밸런스 참고값이며 별도의 합격 조건이 아닙니다. GREAT·GOOD,
  상한·하한에 버려진 변화량과 판정 순서에 따라 종료 HP가 달라집니다.

HP 반영 가중치는 [노트별 정확도](../Gameplay/Rules.md#노트별-정확도와-세션-집계)와
동일하게 논리 노트마다 1로 나누며, `N`은 그 노트 수입니다. 큰 노트의 두 입력은
각각 1/2입니다. 연타형 노트의 목표 입력과 틱형 노트의 각 틱은 해당 노트 정확도의
비율을 따르며, Buzz는 헤드와 몸통 틱에 각각 1/2을 배분합니다. 몸통 틱이 없는 Buzz는
헤드만 사용합니다. 초과 입력과 미완료 항목의 가중치 산정은 기존 정확도 규칙을 따릅니다.
판정 등급이 없는 성공 입력·틱은 자기 가중치의 회복률 100%를 적용합니다. Roll,
BigRoll, Balloon, DengDeng의 회복량은 기본 증가량에 목표 입력 대비 인정 입력의
비율(최대 1)을 곱합니다. 틱형 노트의 성공 틱 회복량도 해당 정확도 가중치에 따릅니다.
타이밍 판정 대상이 아닌 미처리 연타·틱은 회복하지 않으며 별도의 HP 감소도 없습니다.
큰 노트와 롤 노트의 HP는 노트 완료 후 반영합니다. 각 틱은 결과가 확정되는 시점에
개별 반영합니다.

Buzz의 헤드에 판정에 따른 회복률 `H`, 몸통의 성공 틱 비율 `T`를 적용하면
회복량은 기본 증가량의 `0.5 × H + 0.5 × T`입니다. 예를 들어 GREAT 구간 중간인
헤드의 회복률이 0.5이고 몸통 틱의 40%를 성공하면 회복량은 기본 증가량의
0.45배입니다. 헤드의 HP 회복률은 정확도 점수 자체와 같은 값이라는 뜻이 아닙니다.
헤드가 정상 처리되면 해당 헤드의 판정은 확정되고 버즈의 다음 몸통 틱을 대상으로
처리합니다. 이후 입력이 이미 확정된 헤드의 판정·정확도·HP에 영향을 주지 않습니다.
올바른 색을 유지하면서 잘못된 색도 누르고 있는 동안의 틱은 각각 POOR/미처리로
취급하며 회복하지 않습니다. 잘못된 색을 놓고 올바른 색을 유지하면 이후 틱은 다시
처리할 수 있습니다. 예를 들어 헤드 MAX와 몸통 9틱 중 4~6번째 실패, 나머지 성공이면
정확도와 HP 회복률 모두 `0.5 × 1.0 + 0.5 × (6 / 9)`입니다.

POOR는 거부된 입력 자체이므로 발생 즉시 HP를 변경하지 않습니다. 타이밍 판정 노트의
POOR는 이후 올바르게 입력해도 노트 완료 시 최종 정확도 0과 해당 노트의 MISS에 해당하는
HP 감소를 반영합니다. 노트 처리 전까지 기다리는 이유는 배드말림을 방지하기 위해서입니다.
버즈의 확정된 헤드 이후 몸통 틱에 발생한 POOR는 해당 틱만 미처리로 취급하며, 헤드나
다른 틱을 MISS로 바꾸지 않고 추가 HP 감소도 적용하지 않습니다.
버즈 헤드의 POOR는 헤드에만 적용하며 몸통 틱의 가중치를 없애지 않습니다.
일반/큰/보라 노트 POOR 정확도 0과 버즈의 헤드·틱별 POOR 정확도 처리는 구현되었습니다.
그에 대응하는 HP 증감은 여전히 목표 설계입니다.

빈 채보 처리와 YMP에서 조절할 값·문법은 아직 미정이며 HP는 미구현입니다.

`Version`, `JudgeLevel`, BPM·offset 등의 숫자 형식이 잘못된 YMP는 진단을 남기고
곡 선택 catalog에서 해당 패턴만 제외합니다. 같은 catalog의 정상 곡과 패턴은
계속 사용할 수 있습니다. 지정한 YME가 없거나 잘못된 경우도 해당 패턴에 진단을 남깁니다.

BG 경로는 절대경로나 BG 밖으로 나가는 `..`를 허용하지 않습니다. 오프셋은 유한한
2D 좌표여야 합니다. 인게임에서 원본 비율을 유지하고 화면 전체를 덮는 최소 크기로
확대/축소합니다. 오프셋 이동 후에도 빈 가장자리가 생기지 않도록 필요한 배율을 계산합니다.
이미지는 Loading에서 다른 이미지와 함께 준비합니다. 누락/디코드 실패는 기존
배경을 유지하고 오류 HUD에 표시합니다. 채보와 음악의 시간/판정에는 영향을 주지 않습니다.

### 히트사운드 참조

히트사운드 표는 [YME의 HitSounds](Yme.md)에만 둡니다. YMP 노트의 HitSound 칸은
그 표의 인덱스를 참조하며, YME의 시각별 동·캇 기본값 변경보다 우선합니다.
히트사운드 경로 기준은 YME 폴더입니다. YMP에 표 항목을 적으면 로드 오류입니다.

### 일반 노트와 롱노트

기본 한 줄은 다음 순서입니다.

```text
N/D,KeyType,ActionType,HitSound,ExtraData...
```

- `HitSound`와 `ExtraData`는 선택 사항입니다.
- `HitSound`는 비워 두고 옵션만 쓰려면 쉼표를 하나 더 둡니다.
  예: `0/4,12,1,,TickDivision=16`, `0/4,15,1,,8`
- `ActionType`은 `0`이 일반 입력, `1`이 롱노트 시작, `2`가 롱노트 끝입니다.
- 롱노트 시작과 끝은 같은 `KeyType`이어야 합니다. 시작 뒤 같은 Lane에서 끝을
  만나기 전까지 나타난 일반 입력 줄은 현재 Taiko 단일-Lane 규칙상 무시됩니다.

| KeyType | 이름 | 동작 |
| ---: | --- | --- |
| 1 | Don | 동 1회 |
| 2 | Kat | 캇 1회 |
| 3 | BigDon | Good 이내의 동 2회 |
| 4 | BigKat | Good 이내의 캇 2회 |
| 5 | Purple | Good 이내 동·캇 각 1회, 순서 무관. 큰 노트 이미지에 보라색 Ambient 적용 |
| 11 | Roll | 구간 안에서 동·캇 연타. 목표 횟수 이상이면 성공, 정확도는 최대 100% |
| 12 | TickRoll | 작성된 각 틱마다 동·캇 입력을 최대 1회 처리 |
| 13 | BigRoll | Roll과 같은 규칙, 큰 노트 두께로 표시 |
| 14 | BigTickRoll | TickRoll과 같은 규칙, 큰 노트 두께로 표시 |
| 15 | Balloon | 구간 안에서 동을 지정 횟수만큼 입력하면 완료하고 풍선 파열음을 재생 |
| 16 | DengDeng | 구간 안에서 동부터 시작해 동·캇을 번갈아 `HitCount`회 입력하면 완료 |
| 17 | Buzz | 지정한 동 또는 캇을 누르는 동안 각 틱의 히트사운드를 재생 |

롱노트 옵션 이름과 `Don`/`Kat` 값은 대소문자를 구분하지 않습니다. 양의 정수
옵션 범위는 1~1024입니다.

| 노트 | 시작 줄의 옵션 | 설명 |
| --- | --- | --- |
| TickRoll, BigTickRoll | `TickDivision=16` | 온음표를 몇 등분할지 지정합니다. 16은 16분음표 간격입니다. 생략 시 16입니다. 각 틱은 현재 `JudgeLevel`의 Good 범위 안에서 한 번만 받을 수 있습니다. |
| Roll, BigRoll, Balloon, DengDeng | `8` | 목표 입력 횟수입니다. bare 양의 정수와 `HitCount=8`을 모두 지원합니다. 생략하면 롱노트의 정확한 유리수 길이 `L`에 대해 `ceil(L × 12)`회입니다. 길이 `1/4`는 3회, `1/7`은 2회입니다. Balloon은 동만, DengDeng은 동부터 교대합니다. |
| Buzz | `Action=Don,TickDivision=16` | 유지할 입력은 `Don` 또는 `Kat`이며 필수입니다. 틱 분할은 생략 시 16입니다. |

TickRoll은 시작점도 하나의 틱이며 모든 틱은 Good 범위 내 성공/실패만
판정합니다. 세부 등급이나 BAD 감점은 없습니다. Buzz는 시작점을 별도의
타이밍 판정으로 처리하고, 이후 틱만 유지 비율의 분모에 포함합니다.
정확도 계산 및 Debug 표시 계약은 [판정과 정확도](../Gameplay/Rules.md)를 참조합니다.

예시는 다음과 같습니다.

```text
[Pattern]
0/4,11,1,,8
1/4,11,2
2/4,12,1,,TickDivision=16
3/4,12,2
--
0/4,15,1,,8
1/4,15,2
2/4,17,1,,Action=Kat,TickDivision=16
3/4,17,2
```
