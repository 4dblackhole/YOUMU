# 공용 미디어와 랭크 채보 설계 제안

상태: 미구현 설계 제안입니다. 현재 런타임의 파일 형식·서버·라이선스 인증은 변경하지 않았습니다.

## 권장 구조

음악/이미지/BGA 실물은 공용 저장소에 한 번만 두고, 채보에는 자산 ID와 버전을 참조하도록 권합니다.
같은 파일의 중복 import는 콘텐츠 SHA-256으로 합칩니다. 사용자에게 해시 폴더를 직접 편집시키기보다
에디터에서 이름·썸네일로 고르기, 현재 참조 파일 위치 열기, 다른 이미지로 교체하기를 제공합니다.
새 이미지로 수정하면 새 자산 버전으로 등록하고 선택한 채보의 참조만 변경합니다. 다른 채보가 쓰는
기존 이미지가 함께 바뀌는 문제를 피합니다. 실제 경로는 카탈로그가 해석하므로 파일 이동도 한 곳에서 처리합니다.

개념상 Media/Music/<asset-id>, Media/Images/<asset-id>, Media/Video/<asset-id>와
채보별 Patterns/<곡>/<난이도>를 분리할 수 있습니다. 이 경로는 확정된 새 문법이 아닙니다.
현재 배포본은 기존 Asset/Songs/Music, Asset/Songs/Patterns, Asset/Skins 계약을 유지합니다.

| 정보 | 책임 |
| --- | --- |
| 공인 음악 자산 카탈로그 | 안정적인 track ID, 실제 오디오 해시/버전, 사용 가능 여부 |
| YMM | 음악의 제목/아티스트 등 메타데이터. 라이선스 증명으로 신뢰하지 않음 |
| YMP | 연주 노트/타이밍과 해당 채보의 의존성 참조 |
| YME | 판정/스크롤/소리 자동화. 랭크 검증에 반드시 포함 |
| 채보의 기본 배경/BGA 지정 | 공용 미디어 ID를 가리키는 표현 정보 |
| 사용자 배경 교체 | 로컬 표현 설정. YMP/YME 판정 데이터와 분리 |

YME 자체가 판정범위·속도를 바꿀 수 있으므로 배경만 쉽게 교체하려고 YME 전체를 검증에서 제외하면 안 됩니다.
BGA도 화면 장식/영상에 한정해 교체를 허용하고 타이밍·판정 상태를 수정하는 명령을 그 경로에서 실행하지 않습니다.

## 편집본과 랭크본

에디터의 작업본에서는 YME 참조를 바꾸기 쉽게 제공합니다. 공유 YME를 수정할 때는 원본을 덮어쓰는 대신
해당 난이도의 편집본으로 복제하는 방식이 안전합니다. YME 텍스트의 소량 중복은 큰 음원/영상 중복보다 비용이 작습니다.

서버에 게시/랭크할 때는 YMP와 YME를 단일 불변 revision으로 확정합니다. 다른 YME로 교체하거나 내용을
수정하면 원래 revision의 랭크 효력을 유지할 수 없고 새 검토 대상이 됩니다. 파일을 편집하지 못하도록
막는 것과 경쟁 결과를 인증하는 것은 다릅니다. 사용자가 소유한 PC의 파일을 완전히 수정 불가능하게
만들 수는 없으며, 변조된 데이터로 공식 기록을 제출할 수 없도록 해야 합니다.

서버의 manifest에는 chart ID/revision, YMP·YME 각각의 SHA-256, 음악 asset ID/hash,
판정 규칙/파일 형식 버전, 랭크 여부와 판정에 영향을 주는 모든 의존성을 포함합니다.
YMP 안의 YME 참조도 검증하므로 다른 파일 쌍을 끼워 맞출 수 없습니다. 서버 개인키로 manifest를
서명하고 클라이언트는 신뢰한 공개키로 확인합니다. 파일 옆의 수정 가능한 해시 값만 비교해서는 안 됩니다.
해시·서명·버전 메타데이터를 함께 검증하는 원칙은 [TUF 개요](https://theupdateframework.io/docs/overview/)를 참고합니다.
이 게임에 대한 위 manifest 구성은 해당 원칙을 적용한 제안입니다.

점수 서버는 클라이언트의 “검증 성공” 플래그를 신뢰하지 않습니다. 등록된 공식 revision과 입력 로그를
서버가 가진 동일 버전의 판정기로 재계산해야 합니다. 입력은 기존 정수 us와 동시 입력 순서를 보존하고,
글로벌 offset·모드/키 매핑·일시정지/되감기/클리어 자격도 함께 검증합니다. 배포 서명/파일 해시만으로
입력 조작이나 변조한 실행 파일까지 해결되지는 않습니다. 서버 재계산도 리플레이 위조 전반을 자동 해결하지는 않습니다.

## 음악/이미지 라이선스와 BGA

편집 화면은 사용 권한이 있는 공인 음악 카탈로그만 선택하게 하고, 게시 서버에서도 계정의 제작 권한과
실제 오디오 ID/hash를 확인합니다. YMM에 Licensed=true 같은 문자열이 있는지는 증거가 아닙니다.
파일 해시도 사용권 증명이 아니라 등록된 파일의 동일성 확인입니다. 서비스의 권한 데이터가 별도로 필요합니다.

이미지·영상도 같은 라이선스 자산 카탈로그로 관리하되 개인 배경 교체와 공식 기본 자산의 소유/배포 권한을
구분합니다. 계약에서 게임 배포, 이용자의 채보 제작/편집, 이미지 수정과 BGA 결합 사용이 허용되는지는
구매 계약에 따라 별도로 확인해야 합니다. 현재 파일만으로 그 계약 범위는 확인할 수 없습니다.

현재 클라이언트에는 자산 ID/권한 서버, 서명된 랭크 manifest, 서버 판정이나 BGA 재생이 구현되어 있지 않습니다.
다음 구현 전에는 미디어 참조를 둘 파일, 기존 파일의 이동 정책, 랭크 서버 계약을 먼저 확정해야 합니다.
