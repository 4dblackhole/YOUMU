# UI 리디자인 확정 설계

결정: [UI-02](DesignDecisions.md#ui-02-ui-리디자인). 근거는 사용자 확정이고 구현은 **미구현**입니다.
현재 게임은 각 기능 문서의 현재 계약대로 동작합니다. 이 문서는 구현할 다음 화면 설계를
모아 둔 것이며, 구현할 때는 [UI-01](DesignDecisions.md#ui-01-화면과-키-설정)의 절차대로
같은 화면·기능 묶음별로 구현 방식을 브리핑하고 승인받은 뒤 해당 기능 문서로 계약을 옮깁니다.

- 시안: YOUMU 저장소 밖의 `rhythmgameUI/redesign` (YOUMU와 같은 상위 폴더, 별도 비공개 Git 저장소 `rhythmgameUI`).
  `index.html`을 로컬 서버로 엽니다. 시안 폴더의 `README.md`가 화면별 세부 기록입니다.
- 부품 상태표: 같은 폴더의 `kit.html`. 장면 → 역할 → 부품 트리로 쓰이는 곳·논리 크기·상태별 그림을 보여 줍니다.
- 스킨 PNG: [Default Skin Blue](#스킨-부품).
- 색·크기·모양 수치는 시안과 부품 상태표가 기준입니다. 이 문서는 배치·동작·상태·문구 결정을 적습니다.
- 시안의 곡·기록·채보·파형·효과 값은 가상 데이터입니다. 구현은 실제 데이터와 명시적인 빈 상태를 사용합니다.
- 판정 시각·정확도 계산·점수·HP 규칙은 바꾸지 않습니다. 표시만 바꿉니다.

## 공통 규칙

- 화면비: 1280×720 논리 화면, 세로 720 고정. 16:9부터 32:9까지는 논리 폭만 늘어납니다.
  16:9보다 좁은 화면(16:10·4:3·5:4)은 16:9 배치를 그대로 두고 위아래에 거의 검은 남색(`#04070D`) 띠를 둡니다.
  32:9보다 넓으면 좌우에 같은 띠를 둡니다. 좁은 화면용 축소 배치는 따로 두지 않습니다.
- 간격은 8px 격자, 화면 바깥 여백은 32px입니다. 글자는 최소 12px(1080p 18px), 본문 14px 이상입니다.
- 색: 코발트 `#1F4C99`와 사선 결이 기본 면이고 가장 진한 면은 남색 `#142F5E`입니다.
  새벽 금빛 `#F2B23A`는 선택 표시·재생 중 표시·난이도 배지에만 쓰고 밝은 면 위 글자에는 쓰지 않습니다.
  판정 색은 기존 의미 색을 유지합니다.
- 모양: 영역을 감싸는 둥근 카드와 흐림 유리를 쓰지 않습니다. BG 위 양옆 막, 가장자리 없는 빛,
  가는 구분선으로 묶습니다. 강조는 기울어진 평행사변형이고, 남는 둥근 모양은 컨트롤의 2px 모서리·
  스위치·게임 오브젝트뿐입니다. 탭은 밑줄 탭, 입력칸은 밑줄 입력입니다.
- 숫자는 기울인 굵은 압축 글꼴(시안 Barlow Semi Condensed)입니다. 작은 대문자·넓은 자간 라벨은 쓰지 않습니다.
- 날개는 직접 그리지 않고 떠도는 깃털·깃펜 아이콘·흐린 날개 실루엣으로만 암시합니다.
- 버튼 위계: 주 동작은 화면당 하나(코발트 채움, 오른쪽 아래), 보조는 흰 바탕과 코발트 테두리, 3순위는 글자 버튼입니다.
  Back은 왼쪽 아래 남색 모서리 블록, GO·Retry는 오른쪽 아래에서 하단 띠 위로 솟은 블록입니다.
- 문구 최소화: 화면 제목·안내 줄·장식 문구·태그·팝업 설명 문단을 두지 않습니다.
  단축키는 버튼의 툴팁으로 보여 줍니다.
- 팝업: 제목은 왼쪽 위, 닫기(✕)와 Esc는 취소입니다. 바닥 오른쪽에 [Cancel][Apply], Reset은 바닥 왼쪽입니다.
  Play options는 즉시 적용이라 확인 버튼 이름이 `Done`이고, 옵션 패널은 즉시 적용이라 닫기만 있습니다.
- 화면 전환 모션은 이번 설계에 넣지 않습니다.

### 공용 부품

- 드롭다운: 값은 선택 컨트롤이 갖고 펼친 목록만 화면 안에 그립니다. 항목 34px, 8줄을 넘으면 반 줄을 걸쳐
  보이고 스크롤합니다. 고른 항목은 체크와 굵은 코발트, 가리키는 항목은 옅은 코발트 면과 왼쪽 선입니다.
  아래 공간이 없으면 위로 엽니다. 열기 Space·Enter·↑↓·F4, 이동 ↑↓·Home·End·PgUp·PgDn·글자 찾기,
  Enter 고르기, Esc·Tab 닫기이며 뒤 화면 단축키로 새지 않습니다. 항목이 없으면 상자와 목록 모두 `항목 없음`입니다.
- 툴팁: 남색 면과 흰 글자, 대상 아래 8px(공간이 없으면 위)입니다. 0.5초 머문 뒤 나타나고 옆 대상으로 옮기면
  곧바로 바뀝니다. 단축키는 이름 오른쪽 글자 칩입니다. 키보드 포커스로도 나타나고 누르기·휠·키 입력·화면 전환에 사라집니다.
- 스크롤바: 잡는 폭 12px, 보이는 막대 6px 평평한 코발트, 옅은 레일, 화살표 없음, 누르는 동안 진한 코발트입니다.
  가로 스크롤바는 8px입니다. 여러 줄 입력칸에는 크기 조절 손잡이가 없습니다.
- FPS 표시(F7): 오른쪽 아래 모서리에 붙은 남색 띠, `FPS 144 | UPS 1000` 형식입니다.
- 한글·일본어 입력 조합: 확정되지 않은 글자는 옅은 코발트 바탕과 코발트 2px 점선 밑줄, 커서는 조합 글자 바로 뒤입니다.
  후보 창은 Windows가 그립니다. 검색창·입력칸·여러 줄 입력칸에 공통입니다.

### 경고·오류

- 경고·오류 대화상자는 하나를 공용으로 씁니다. 심각도(error 빨강·warning 금빛·info 코발트)는 위 4px 띠와 아이콘 색,
  제목은 영어, 설명은 선택 언어, 원문 진단(경로·오류 코드)은 고정폭 상자에 선택·복사할 수 있게 둡니다.
  주 버튼은 오른쪽 끝(Enter)이고, 되돌릴 수 없는 동작(Discard 등)은 왼쪽 끝으로 떨어뜨리며, Esc는 취소 동작입니다.
- 대화상자는 작업이 멈췄거나 데이터에 영향이 있을 때만 씁니다. 저장 실패·붙여넣기 형식 오류·파일 열기 실패·
  .osu 변환 실패·에디터 미저장 확인·결과 기록 저장 실패가 해당합니다. 입력칸 하나의 잘못은 그 자리의 상태 문구나
  GO 말풍선으로 알리고 흐름을 끊지 않습니다.
- 화면 오류 줄(플레이·로딩 공용): 화면 위 가운데에 흰 막과 왼쪽 빨간 표지, 종류·파일 경로와 행·원인을 한 줄로 둡니다.
  일시정지 덮개 위에 떠서 메뉴가 열려도 읽힙니다.

## 타이틀

- YOUMU 글자 자리에 음악 플레이어를 둡니다. 앨범 아트(그 곡 패턴의 BG, 없으면 곡 색과 흐린 날개 실루엣),
  아티스트/곡명, 진행 막대(클릭·끌기로 이동), 이전·재생/일시정지·다음, 음량·음소거입니다.
  양옆 막대는 주파수 시각화이고 바깥으로 갈수록 짧아집니다.
- 재생 목록은 곡 선택 목록(검색·필터·정렬 반영)입니다. 처음에는 임의의 곡을 골라 두고, 곡이 끝나면 다음 곡,
  이전 버튼은 3초 넘게 들었으면 그 곡 처음으로 갑니다.
- 키: ←/→ 이전·다음 곡, Space 재생/일시정지, Enter 메뉴 실행입니다. Space는 메뉴를 실행하지 않습니다.
- 하늘 배경에는 구름 없이 깃털만 떠돕니다. 선택한 메뉴는 오른쪽으로 밀리고 코발트 면 안 왼쪽에 금빛 깃털 커서가 들어옵니다.
- 곡이 없으면 아트는 빈 상자, 곡명·아티스트는 빈 글자, 재생 조작은 꺼짐입니다. 다른 곡으로 대신 채우지 않습니다.
- 이전 rhythmgameUI의 타이틀 캐러셀은 계속 폐기 상태입니다.

## 곡 선택

- 배치: 왼쪽 기록, 가운데 선택한 곡·패턴 정보, 오른쪽 곡 목록입니다. 감싸는 패널 대신 양옆 막과 가운데 빛을 씁니다.
  가운데 정보는 재킷·곡 정보·수치를 세로 가운데 정렬합니다.
- 곡 정보는 아티스트·곡명·채보 제작자를 각각 다른 줄에 둡니다. 이름이 여러 개면 대표(첫 번째) 하나만 보이고
  전체는 툴팁으로 보여 줍니다. 검색은 모든 이름을 대상으로 합니다.
- 곡 목록 위에 탭 한 줄(All + 즐겨찾기 폴더)을 두고 ★는 폴더 관리입니다. 별도 `ALL` 바는 없습니다.
- 하단 띠: Back은 왼쪽 끝, GO는 오른쪽 끝의 유일한 주 버튼입니다. 가운데에 게임 모드·Play options·옵션(톱니, 툴팁 Ctrl+O)을 둡니다.
  GO 오류는 GO 바로 위 말풍선입니다.
- 키: ↑/↓는 곡과 난이도를 한 칸씩 이동합니다. 마지막 난이도에서 ↓는 다음 곡의 첫 난이도,
  첫 난이도에서 ↑는 이전 곡의 마지막 난이도입니다. ←/→는 곡 단위 이동입니다. 펼친 난이도는 세로 목록입니다.
  난이도 칸은 첫 클릭이 선택, 같은 칸을 다시 누르면 시작입니다.
- 난이도 값: Lv 대신 클라이언트가 계산한 난이도(소수 둘째 자리)를 목록·상세·로딩·결과에 같은 값으로 씁니다.
  미계산은 `—`이며 Difficulty 정렬에서 뒤로 가고 Difficulty 범위 필터에서는 제외됩니다. 계산식과 척도는 미정입니다.
- 기록: 기록이 없는 패턴은 설명 없이 숫자 글꼴 `NO RECORD` 한 줄입니다. 기록 파일 손상·미지원 버전은 기록 칸에
  빨간 표지·원인·파일 위치와 지우지 않고 보존했다는 안내를 두고 BEST·페이지는 비웁니다.
- 패턴이 없는 곡: 목록에 나오고 펼친 카드의 난이도 자리에 숫자 글꼴 `NO DIFFICULTIES`를 둡니다.
  상세의 곡명·아티스트·재킷은 그대로, 난이도·수치 칸은 비우고 기록 칸도 비웁니다. GO는 꺼지고 미리듣기는 재생합니다.
  ↑/↓는 그 곡을 한 칸으로 지나갑니다.
- 곡이 하나도 없을 때: 목록 자리에 `NO DIFFICULTIES` 한 줄, 곡 BG 없이 스킨 하늘 배경, 기록·정보 칸은 비웁니다.
  검색·필터로 목록이 빈 경우는 기존처럼 바꿀 방법을 안내하고 기록·정보 칸을 유지합니다.
- 첫 목록 로딩 문구는 없습니다. 점진 게시는 [LOAD-01](DesignDecisions.md#load-01-로딩과-캐시)입니다.
- 미리듣기: 타이틀에서 재생 중이던 곡을 선택한 채로 들어가 끊김 없이 이어집니다. 다른 곡으로 옮기면 200ms 페이드로
  그 곡을 처음부터 재생하고 반복하며, 난이도만 바꾸면 끊지 않습니다. 선택한 곡 제목 앞에 재생 중 표시를 둡니다.
  로딩·플레이·결과에서는 멈추고 결과에서 돌아오면 선택한 곡을 다시 재생합니다.

## 에디터 곡 선택

- 게임 곡 선택과 같은 화면에서 기록 열만 빠지고 그 자리에는 BG가 보입니다. 곡 정보·곡 목록은 같은 자리·같은 모양입니다.
- 에디터 전용은 곡 카드의 `+`(New Difficulty·Convert .osu)뿐이고 하단 가운데는 옵션 톱니 하나입니다.
  예전 에디터 전용 패턴 비교표와 넓은 상세 배치는 없습니다. 패턴이 없는 곡의 `+`에는 금빛 밑줄을 둡니다.
- New Difficulty는 입력 창 없이 에디터 Metadata 탭의 만들기 전 상태로 들어갑니다(`New` 표시, 저장 버튼은 Create,
  Compose·Audio 탭 잠김). Create 때 HP 범위를 함께 검사합니다.
- Convert .osu는 OS 파일 탐색기로 고르고, 변환이 끝나면 곡 목록에 자동으로 추가합니다.
  진행·완료 표시는 없고 실패만 경고 대화상자입니다.

## 플레이 옵션과 필터

- Play options의 Difficulty 열 맨 아래에 `HP gauge` 선택과 그 게이지의 클리어 기준(`Clear 60%`)을 둡니다.
  지금은 Default 하나이며 추가 게이지는 [HP-02](DesignDecisions.md#hp-02-hp-구조와-미정점)대로 미정입니다.
  선택한 게이지의 기준은 플레이 HP 게이지의 클리어 표시와 결과 HP 그래프의 클리어선에 같이 쓰고,
  기본이 아닐 때만 선곡 Play options 표시와 결과 옵션 칩에 나타냅니다.
- 곡 필터는 범위 조건에 직접 조건식을 더해 AND로 묶습니다. 패턴 필드는 Notes·BPM·MinBPM·MaxBPM·JudgeLevel·HP·
  Difficulty·Length(초)·Mode·Tag입니다. 글자 값은 따옴표, Mode·Tag는 `=`/`!=`만, 미계산 난이도는 어떤 비교도 거짓,
  Tag는 태그 중 하나라도 같으면 참입니다.
- 조건식 편집 창(기록 필터·곡 필터 공통): 입력하는 동안 검사해 오류와 위치(몇 번째 글자)를 표시하고, 필드·연산자 칩은
  커서 위치에 넣습니다. Ctrl+Enter가 Apply입니다. 적용한 식은 기록 필터의 편집본에 들어가고 기록 필터 Apply 때 확정됩니다.
- 키 설정: 폭 432입니다. 열 머리는 플레이 입력 패널과 같은 키 그림, 첫 칸은 메인(크게), 아래 세 칸은 보조입니다.
  Main/Sub 글자와 빈 칸 문구를 빼고 빈 칸은 흐린 +, 비우기 ×는 마우스를 올릴 때만 보입니다.
  안내는 입력 대기·오류일 때만 둡니다.

## 옵션 패널

- 폭 432: 왼쪽에 분류 막대(폭 64, General·Display·Audio·Input 아이콘), 오른쪽에 본문(폭 368)입니다.
  막대에 0.3초 머물거나 키보드로 들어오면 분류 이름이 펼쳐져 본문 위를 덮습니다.
- 본문은 탭 전환 대신 모든 분류가 이어진 섹션입니다. 분류를 누르면 그 섹션으로 스크롤하고, 직접 스크롤하면 맨 위에 걸린
  섹션(끝까지 내리면 마지막 섹션)이 켜집니다. 켜진 분류는 금빛 왼쪽 줄입니다. 분류 막대에서 ↑/↓로 이동합니다.
- 다시 열면 스크롤 위치와 분류를 유지합니다. 오류·복구 안내는 본문 밖 아래 칸에 둡니다.
- 여는 곳(로고 옵션 버튼·선곡 톱니·Ctrl+O)과 즉시 적용 규칙은 기존과 같습니다.

## 로딩

- 화면 가로 띠에 곡·패턴 소개를 둡니다.
- 준비 실패: 화면 오류 줄과 일시정지 메뉴를 함께 띄웁니다. Resume·Rewind는 꺼지고 Retry는 다시 준비, Retire는 결과입니다.
  로딩 카드는 메뉴와 겹치지 않게 숨깁니다.

## 플레이

- 기어는 실제 게임 에셋 배치를 유지합니다. 바꾸는 점: 입력 패널의 무채색 회색을 기어 바탕색(`#BAD1ED`) 색조로,
  콤보 라벨을 진한 잉크로, 키 누름을 밝고 선명하게, 마디선을 2px·50%로 합니다. 기어 테두리는 코발트입니다.
- 타이밍 인디케이터는 판정원 바로 아래에 두고 0점을 판정원 x에 맞춥니다. 진행바와 겹치지 않습니다.
- 정확도는 오른쪽 위에 고정하고 라벨 없이 숫자만 둡니다. 100.00% 폭을 미리 잡아 상자 폭이 흔들리지 않습니다.
- HUD 문구에는 흰 반투명 바탕판을 둡니다.
- 판정 문구·판정 이미지는 이번 설계에서 바꾸지 않습니다.
- Kiai 구간에서는 판정원을 강화합니다. 같은 판정원 PNG를 옅은 금빛으로, 뒤에 호박색 빛, 바깥에 금빛 고리 한 겹을 두고
  박마다 살짝 커졌다 줄어듭니다(움직임 줄이기 설정이면 고정). 켜고 꺼질 때 250ms 페이드입니다.
- 풍선·뎅뎅은 일반 노트와 같은 원판 × RollGold와 흰 테두리에 매듭·손잡이만 더해 그립니다. 처리 중 중앙 그림은 같은 모양을
  크게 그리며, 풍선은 칠수록 0.72→1.10배로 커지고 다 치면 터지며 뎅뎅은 돌다가 사라집니다.
  남은 타격 수는 남색 블록·금빛 표지·흰 기울인 숫자 배지 하나로 통일합니다(롤은 판정원 오른쪽 위, 풍선·뎅뎅은 중앙 그림 아래).
- 플레이 종료 배너는 두지 않습니다.

### 정확도 표시

- 플레이·결과·기록·노트 그룹 모두 소수점 둘째 자리까지 표시하고 그 아래는 반올림하지 않고 버립니다
  (99.999999 → 99.99, 100.00은 정말 100%일 때만).
- 계산·저장·랭크 판정은 기존 0.000001% 단위 값을 그대로 씁니다([GAME-02](DesignDecisions.md#game-02-판정과-정확도)).

### HP 게이지 표시

- 스킨 부품 다섯 개: 틀(항상 같음), 채움 두 종류(클리어 기준 전 Low = 코발트와 결, 기준 이상 Clear = 새벽 금빛과 밝은 결),
  클리어 표시(게이지 종류의 기준 자리에 남색 2px 선과 틀 위로 나온 역삼각), 자물쇠입니다.
- 틀은 화면 왼쪽 끝부터 490×24, 기어 위 16px입니다. 왼쪽 32px은 자물쇠 받침, 그 오른쪽에 454×18 칸과 10% 눈금입니다.
- 채움은 칸과 같은 크기의 그림을 HP만큼 왼쪽부터 잘라 보입니다(늘이지 않음). HP가 기준 이상이면 Clear 채움으로 바꿉니다.
- 일시정지 메뉴나 Rewind를 처음 쓴 순간 그 시도의 HP가 꺼지면([Pause](Gameplay/Pause.md#hp리플레이와-기록의-연동-계약))
  받침 위에 흰 칸과 남색 자물쇠가 내려오고 채움은 그 자리에 멈춥니다. Retry면 사라집니다.
- 숫자는 표시하지 않습니다. 게이지 규칙은 [HP-01](DesignDecisions.md#hp-01-기본-hp-설계)·HP-02 그대로입니다.

## 일시정지

- 큰 기울인 `PAUSED` 제목 아래 Resume·Rewind(값 선택기)·Retry·Retire 네 행입니다. Retry·Retire 설명을 두고,
  Retire는 구분선과 위험 색으로 떨어뜨립니다. 선택 행은 금빛 왼쪽 줄입니다.
  배경은 흐림 유리 대신 사선 결이 있는 남색 덮개입니다.
- 준비 중: Resume·Rewind를 고르면 메뉴가 닫히고 음악을 맞추는 동안 화면은 멈춥니다. 그 사이 Esc로 메뉴를 열면 `PAUSED` 아래
  가는 코발트 진행 띠가 움직이고 Resume·Rewind 행과 값 선택기는 꺼집니다(바탕은 그대로, 글자·선택기 40%).
  준비가 끝나면 띠가 사라지고 두 행이 다시 켜지며 메뉴는 그대로입니다. 움직임 줄이기 설정이면 띠는 멈춰 있습니다.
- 로딩 준비 실패 때도 같은 꺼짐 모양을 씁니다.

## 결과

- 상단 배너: 모드 배지, 곡명·아티스트, 난이도와 난이도 값 배지, 채보 제작자입니다.
- 왼쪽 열(폭 340, 위에서 아래로): HP 그래프(세로 눈금 100·클리어 기준 점선·0, 그래프 안 글자 없음,
  제목 줄에 `실패`와 일시정지·Rewind 사용 표시) → 정확도(크게)와 최대 콤보(작게, 오른쪽 끝) 한 줄 →
  판정 개수 두 열(MAX·PERFECT·GREAT·GOOD / BAD·OK·MISS·POOR, 판정 색 표시와 숫자) → Ticks → 노트 그룹별 정확도 → 노트 수 합계.
  이력이 없으면 축과 클리어선만 두고 가운데 `데이터 없음`입니다.
- 가운데: 랭크와 점수를 원형 띠로 감쌉니다. 띠는 12시부터 시계방향으로 MAX→PERFECT→GREAT→GOOD→BAD→OK→MISS→POOR
  비율을 판정 색 조각으로 그리고, 조각에 마우스를 올리면 개수와 비율을 보여 줍니다. 띠 밑에 적용한 플레이 옵션을 둡니다.
  랭크 글자는 코발트와 흰 외곽이며 날개 장식은 없습니다.
- 오른쪽: Timing 그래프만 둡니다(탭 없음). 평균·표준편차는 그래프 위에 둡니다.
- 버튼: Back(왼쪽 아래), Retry(오른쪽 아래 솟은 블록), Replay입니다.
- 기록 저장 실패: 공용 대화상자(파일 경로·원인, 닫기·다시 시도)를 띄우고 결과 화면은 그대로 두며 아래 저장 줄은 빨간 `기록 저장 실패`입니다.

### 랭크 이름

랭크 이름은 최대 3자입니다. 하한은 [기존 표](Gameplay/Results.md#정확도-랭크)와 같고 각 하한을 포함합니다.

| 정확도 | 현재 이름 | 확정 이름 |
| --- | --- | --- |
| 100% | Y | Y |
| 99% 이상 | PERFECT | X |
| 98% 이상 | SSS | SS |
| 96% 이상 | SS | S |
| 93% 이상 | S | AA |
| 90%·85%·80%·75%·70% 이상 | A·B·C·D·E | A·B·C·D·E |
| 그 아래 | F | F |

skin.ini 랭크 키와 PNG 파일 이름을 새 이름으로 바꿀지는 구현 때 정합니다.

## 리플레이

- 별도 화면 없이 플레이 화면에 버튼 몇 개만 더합니다. 게임 키 입력은 받지 않습니다. 왼쪽 위에 `REPLAY` 표시를 둡니다.
- 진행 막대 왼쪽 끝: Back(남색 모서리 블록, Esc)·재생/정지(Space)·−5s/+5s(←/→).
  오른쪽 끝: 속도 −/+(0.25–2.00x, 0.25씩, 값을 누르면 1.00x, 1.00x가 아니면 금빛 밑줄).
- 진행 막대는 높이를 키워 누르거나 끌어서 이동합니다. 이동하면 그 시각까지 다시 판정해 HP·콤보·판정 수가 그 시각 상태가 됩니다.
- 제어 표시([Pause](Gameplay/Pause.md#hp리플레이와-기록의-연동-계약) 계약): 원래 플레이의 일시정지는 막대 위 남색 깃발과
  막대를 지나는 줄기, Resume·Rewind는 막대 아래 코발트 꺾쇠(출발→도착, 도착 쪽 화살촉, Rewind가 더 깊음)입니다.
  마우스를 올리면 시각 툴팁입니다. 정지 시간·되감기 움직임은 재현하지 않고, 첫 일시정지 시각부터 HP 게이지에 자물쇠를 둡니다.
- 끝나거나 Back이면 결과로 돌아가며 기록은 바뀌지 않습니다.
- 리플레이 재생·파일 저장 자체는 [DATA-01](DesignDecisions.md#data-01-결과와-기록)대로 미구현입니다.

## 차트 에디터

- 탭은 Compose·Audio·Metadata입니다. 예전 Pattern·Timing·Effects 탭은 Compose 하나로 합칩니다.
  Test 버튼은 없애고 저장한 채보의 Test 플레이는 Compose의 Preview가 대신합니다.
- 위: 남색 메뉴 줄(File·Edit, Alt+F·Alt+E·F10), 문서 이름(대표 곡명·아티스트·[난이도]), 저장 안 함 표시(금빛 점).
  아래 띠: Back·재생/현재 시각(입력 가능)·재생 속도 −/+(0.25–2.00x, 0.05씩, Shift는 0.25씩, 값을 누르면 1.00x)·
  타임라인·Save(Ctrl+S). 재생 속도는 모든 탭에 공통입니다.
- Back/Esc는 저장하지 않았으면 공용 대화상자(Discard·Cancel·Save)입니다.
- Compose
  - 도구 줄: 하위 보기 Realtime·Score·Preview, 노트 도구(Q 선택·W 동/캇·E 큰 노트/보라·R 롤·T 틱롤·Y 풍선/뎅뎅·U 버즈,
    같은 키를 다시 누르면 묶음 안에서 순환, 도구 버튼 우클릭은 그 묶음의 변형 팝업), Beat 눈금(1/1–1/16, 1/17–1/1024 직접 입력).
  - Realtime: 눈금자, 레인(플레이와 같은 에셋), 그 아래 채널 Music(파형)·Timing(BPM·마디 길이·delay)·Scroll speed·
    Volume(대상별 곡선)·Audio FX(Reverb send·Low-pass·High-pass)·Hit sounds·Zones(Syncopation·Kiai·Bar lines 세 줄)를
    같은 시간축에 쌓습니다. 레인은 [EDIT-01](DesignDecisions.md#edit-01-에디터)대로 속도 효과를 적용하지 않은 등속 축입니다.
  - 채널 머리 맨 왼쪽 버튼은 그 요소의 편집 패널(오른쪽, 내용을 밀어냄)을 열고, 머리 오른쪽에 현재 시각의 값을 둡니다.
    레인 머리의 Spacing −/+와 Ctrl+휠은 노트 간격(시간축)만 바꿉니다.
  - 편집 패널: 목록과 선택 항목 편집, 여러 행 선택(클릭·Ctrl+클릭·Shift+클릭), Delete·Add·Apply 줄 고정.
    음수 delay로 잘린 구간은 빨간 빗금입니다. 영역 효과의 Curve는 기본 3개와 사용자 곡선이며 곡선 편집 창에서 식을 고칩니다.
  - 구간 선택: Q 도구로 끌면 박자 눈금에 맞춘 구간, Ctrl+C는 앞뒤 빈 간격과 함께 복사, Delete는 구간 노트 삭제입니다.
  - Score: 패턴만 악보처럼 박마다 같은 간격으로 그려 반복 패턴의 일관성을 봅니다.
  - Preview: 실제 플레이 화면과 같은 모습에 속도 효과를 적용한 읽기 전용 보기입니다.
- Audio: Metronome, 보이는 범위 −/+, Offset ±1 ms, 파형·음악 FFT·예상 히트사운드 FFT를 같은 시간축에 둡니다.
- Metadata: Name·Chart by(여러 명, 첫 줄 ★이 대표)·Tags·JudgeLevel·HP·Base BPM·Offset / Music·Effect file·BG(미리보기, x·y) / Hit sounds 표입니다.
- 붙여넣을 내용이 채보 형식이 아니면 `Paste failed` 대화상자입니다.

## 스킨 부품

- 부품 상태표(`kit.html`)는 스킨 제작자용 문서입니다. 상태 이름은 기본·마우스 올림·누름·키보드 포커스·꺼짐·선택·켜짐·펼침·입력 대기입니다.
- `YOUMU.Assets/Assets/Skins/Default Skin Blue`에 시안 부품을 Default Skin과 같은 폴더 구조의 투명 PNG로 둡니다.
  1080p 기준(논리 × 1.5)이고 글자는 굽지 않으며, 버튼 라벨 아이콘은 `Common/Icons`에 따로 둡니다.
  상태 이미지는 `이름.Hovered.png`처럼 skin.ini 키와 같은 이름입니다. 폴더의 `README.md`가 파일 목록입니다.
- 이 폴더의 skin.ini는 게임에 이미 있는 키만 연결합니다. HP 게이지·리플레이 표시·옵션·에디터·Common 같은 새 부품은
  읽는 키가 없어 파일만 둡니다. 내장 자산 팩에는 들어가지 않습니다([BuiltInAssets](BuiltInAssets.md#포함-범위)).
- PNG는 시안 폴더의 `tools/skin_export.py`, 상태표 그림은 `tools/kit_capture.py`로 다시 만듭니다.
- 실제 스킨 파일 이름·9-slice 여부·새 skin.ini 키는 구현 때 정합니다.
